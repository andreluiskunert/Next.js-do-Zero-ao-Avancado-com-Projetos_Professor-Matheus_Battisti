# 🚀 Curso Completo de Next.js

Seja bem-vindo ao nosso **curso completo de Next.js**!

Se você está pronto para dominar este poderoso framework de desenvolvimento web baseado em **React**, você está no lugar certo.

Este curso foi desenvolvido para levar você **do nível básico ao avançado**, capacitando-o a criar aplicações web completas, escaláveis, modernas e de alto desempenho.

---

# 🎯 Objetivos do Curso

Ao longo do curso, você aprenderá a:

* Criar projetos com Next.js.
* Compreender a estrutura de aplicações Next.js.
* Trabalhar com páginas e navegação.
* Criar rotas dinâmicas e aninhadas.
* Utilizar Server Components e Client Components.
* Trabalhar com `useRouter` e `redirect`.
* Estilizar aplicações com diferentes tecnologias.
* Buscar e manipular dados.
* Utilizar Server Actions.
* Trabalhar com bancos de dados utilizando Prisma.
* Implementar autenticação.
* Utilizar NextAuth.
* Trabalhar com cache.
* Criar aplicações completas e escaláveis.
* Desenvolver um projeto prático semelhante ao Instagram.

# 📚 Conteúdo do Curso

## 1. 🟢 Introdução ao Next.js

Nesta primeira seção, serão apresentadas as principais vantagens do **Next.js em relação ao React**.

### Conteúdos:

* Configuração do ambiente de desenvolvimento.
* Criação do primeiro projeto.
* Estrutura de diretórios e arquivos.
* Principais conceitos do Next.js.
* Diferenças entre Next.js e React.
* Renderização do lado do servidor (**SSR**).
* Renderização do lado do cliente (**CSR**).

O objetivo é criar uma base sólida para compreender o funcionamento do framework.

---

# 2. 🧭 Páginas e Navegação

Nesta etapa, será explorado o sistema de roteamento do Next.js.

### Conteúdos:

* Roteamento baseado em arquivos.
* Navegação entre páginas.
* Páginas dinâmicas.
* Parâmetros de rotas.
* Rotas aninhadas.
* Layouts reutilizáveis.
* Hook `useRouter`.
* Função `redirect`.
* Server Components.
* Client Components.
* Diretiva `"use client"`.

---

# 3. 🎨 Estilização

Nesta seção, serão apresentadas diferentes maneiras de estilizar aplicações Next.js.

### Tecnologias e abordagens:

* CSS Global.
* CSS Modules.
* Tailwind CSS.
* SASS.
* CSS-in-JS.

O objetivo é conhecer diferentes estratégias de estilização e escolher a abordagem mais adequada para cada projeto.
